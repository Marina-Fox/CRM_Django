# Django-CRM_system

CRM-система на Django.

# Основные функции:

* Авторизация пользователя;
* Создание, редактирование и просмотр предоставляемых услуг;
* Создание, редактирование и просмотр рекламных кампаний;
* Создание, редактирование и просмотр потенциальных клиентов;
* Создание, редактирование и просмотр контрактов с клиентами;
* Перевод потенциального клиента в активного;
* Подсчет и отображение статистики по рекламным кампаниям:
    - число клиентов, привлеченных рекламной кампанией;
    - число клиентов, перешедших из потенциальных в активные;
    - окупаемость рекламы.

# Стек технологий:

Python Django PostgreSQL

# Установка и запуск:

## Локально

1. Клонировать репозиторий;
2. Создать файлы .env.app, .env.db, .env.superuser и заполнить их согласно шаблону;
3. Собрать и запустить сервисы командой:

> docker compose up --build -d

4. Открыть страницу браузера по пути, указанному в ALLOWED_HOSTS в своем файле .env.app;
5. Войти в аккаунт суперпользователя:

> Логин и пароль должны быть назначены в файле .env.superuser (DJANGO_SUPERUSER_USERNAME и DJANGO_SUPERUSER_PASSWORD) перед сборкой.

6. В административной панели создать пользователей и добавить каждого из них в нужную группу:

> Admins -- администратор: работает через административную панель. Может создавать/просматривать/редактировать/удалять других пользователей и добавлять их в группы.

> Marketing -- маркетолог: работает с сайтом. Может создавать/просматривать/редактировать/удалять предоставляемые услуги и рекламные кампании.

> Operators -- оператор: работает с сайтом. Может создавать/просматривать/редактировать/удалять потенциальных клиентов.

> Managers -- менеджер: работает с сайтом. Может создавать/просматривать/редактировать/удалять контракты; просматривать потенциальных клиентов и переводить их в активных; просматривать статистику рекламных кампаний.

## На удаленном сервере

1. Клонировать репозиторий на удаленный сервер (ветка deploy):

> git clon --branch deploy --single-branch https://github.com/Marina-Fox/CRM_Django.git

2. Создать файлы .env.app, .env.db, .env.superuser и заполнить их согласно шаблону;
3. Сделать файлы доступными только владельцу:

> chmod 600 .env.app .env.db .env.superuser

4. Редактировать файл nginx.conf (добавить публичный IP в server_name);
5. Установить docker согласно документации;
6. Загрузить образы и запустить контейнеры:

> docker compose -f compose.prod.yml up -d --pull always

7. Открыть страницу браузера по публичному IP;
8. Далее пункты 5 и 6 при локальном запуске (см выше).
